# Digital Logic Clock

## Overview
This project is a digital clock built using digital logic ICs, a signal generator, and seven-segment displays to count and display time.

## Video
[digital-clock-prototype.mp4](digital-clock-prototype.mp4)

## Hardware
- Digital logic ICs
- Seven-segment displays
- Signal generator
- Breadboards
- Jumper wires
- 0.1 µF and 10 µF capacitors

## Known Issue
The clock was intentionally set to run faster than real time for testing, but the final counting speed was faster than intended.

## What I Learned
- Working with digital logic circuits
- Using seven-segment displays
- Building and wiring a larger breadboard circuit
- Troubleshooting circuit connections
